# DHCP & DNS Server Setup Lab

## Objective
Configure DHCP and DNS servers on a virtual Ubuntu server for a small office simulation.

## Tools Used
- VirtualBox
- Ubuntu Server 22.04
- Windows 10 Client VM

## Steps
1. Installed and configured isc-dhcp-server
2. Configured static IP and subnet
3. Installed and configured bind9
4. Verified domain resolution from client VM
